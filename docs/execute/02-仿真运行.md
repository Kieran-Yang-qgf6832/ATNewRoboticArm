# 02 仿真运行

## 直接起仿真

```bash
source /opt/ros/jazzy/setup.bash && source install/setup.bash

# 仿真 + RViz
ros2 launch launch_pack arm_controller_test_sim.launch.py

# 无界面（纯命令行）
ros2 launch launch_pack arm_controller_test_sim.launch.py headless:=true show_rviz:=false
```

控制器激活后会自动执行一次 `reset`（`exp_state: reset`），把机械臂拉到零位并回到 `idel`。

## 一条龙：仿真 + 任务（推荐）

```bash
# 默认打开 Qt joint_console；任务/UI 退出后自动关仿真
ros2 launch launch_pack arm_task_sim.launch.py

# 任意序列
ros2 launch launch_pack arm_task_sim.launch.py task_sequence:=pos_move_demo

# 常驻，之后可改参数换序列
ros2 launch launch_pack arm_task_sim.launch.py exit_when_idle:=false
ros2 param set /task_runner task_sequence "pick_demo"
```

常用 launch 参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `task_sequence` | `joint_console_ui` | `tasks.yaml` 里的序列名 |
| `tasks_config` | `tasks/config/tasks.yaml` | 任务 YAML 路径 |
| `mujoco_model` | `arm_model/model/scene.xml` | MJCF 场景 |
| `headless` | `false` | 关掉 MuJoCo UI |
| `show_rviz` | `false` | 是否启动 RViz |
| `controller_overlay` | 空映射 | 控制器参数叠加文件（real-compat 用） |
| `exit_when_idle` | `true` | 任务结束后是否关掉整个 launch |

## 控制器状态

| 状态 | 用途 |
| --- | --- |
| `idel` | 锁定当前位置（带重力前馈） |
| `reset` | 复位到 `reset_joint_pos` |
| `cart_traj` | 笛卡尔轨迹（含 `pos_move` / `box_move`） |
| `joint_traj` | 关节轨迹（含多路点） |
| `servo` | 速度积分伺服 |
| `admittance` | 导纳控制 |
| `teach_pendant` | 示教拖动 |
| `measure` | 参数辨识测量 |

```bash
ros2 param set /arm_controller exp_state reset
ros2 param get /arm_controller exp_state
```

## 多路点轨迹

`joint_waypoints` / `cart_waypoints` 是控制器内建的 C3 轨迹：

```bash
ros2 run tasks waypoint_check --mode joint --expected '[[0,0,0,0,0,0]]'
```

必须在轨迹执行前启动，等待 `/arm_waypoints_duration`。详见 [任务层与序列](05-任务层与序列.md)。
