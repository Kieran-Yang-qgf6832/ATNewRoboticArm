# 01 环境依赖与构建

## 系统要求

- ROS 2 Jazzy / Ubuntu 24.04 / Python 3.12
- ROS 2：`ros2_control`（`controller_interface`、`hardware_interface`、
  `controller_manager`、`realtime_tools`）、`rclcpp`、`rclcpp_lifecycle`、`pluginlib`
- 计算：Pinocchio、Eigen3、`kdl_parser` / `orocos_kdl`
- 通信：`libusb-1.0`（USB CDC）
- 配置：`yaml-cpp`
- 仿真：MuJoCo（`src/mujoco_ros2_control` 随仓库提供）
- Python：`numpy`、`scipy`、`pinocchio`、`pyyaml`；物理一致性重建需要 `picos` + `cvxopt`
- 视觉：`python3-opencv`、`numpy`；实机相机驱动 `realsense2_camera`
- Qt 版 `joint_console`：`qtbase5-dev` + 图形会话（`DISPLAY` 或 `WAYLAND_DISPLAY`）

## 构建

```bash
cd <项目根目录>
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install
source install/setup.bash
```

只构建核心包（快速验证）：

```bash
colcon build --packages-select arm_controller tasks --symlink-install
colcon build --packages-select arm_controller parameter_identify --symlink-install
```

`--symlink-install` 让 `install/` 指向 `src/`：改 YAML、launch、Python 不需要重新编译；
改 C++ 仍需重新 `colcon build`。

## 常见构建问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `failed to create symbolic link ... Is a directory` | `build/<包名>/ament_cmake_python/...` 下有陈旧目录 | 删掉那个同名目录再构建 |
| `ModuleNotFoundError: No module named 'ament_package'` | 没有 source ROS 2 环境，或 `python3` 指向了别的环境 | `source /opt/ros/jazzy/setup.bash` 后再构建 |
| 改了 YAML 不生效 | 不是 `--symlink-install`，或控制器只在构造期读参数 | 重新构建/安装，并重启控制器（C6） |
| `Doxygen need to be installed` | 只影响文档生成，不影响构建 | 可忽略 |
