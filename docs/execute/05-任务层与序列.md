# 05 任务层与序列

任务层是**配置驱动的步骤执行器**：任务写在 `src/tasks/config/tasks.yaml`，新增任务不需要
改 C++；新增**步骤类型**才需要改 `src/tasks/executor/step_types.cpp` 的 `step_spec()`。

## YAML 结构

```yaml
tool:            # 末端执行器语义名 → 开关量
points:          # 命名关节目标点（6 个关节角，rad）
positions:       # 命名基座系位置（pos_move 用）
position_move:   # pos_move 默认参数
box_move:        # 视觉目标帧、tool_offset、超时
joint_limits:    # joint_console 的限位门禁（度）
sequences:       # 序列 → steps
```

## 步骤类型（封闭集合，14 类）

| 类型 | 说明 |
| --- | --- |
| `wait` | 纯等待 |
| `idel` | 切回 `idel` |
| `reset` | 复位并等待回到 `idel` |
| `joint_move` | 关节轨迹（`to` 引用目标点或 `target` 直接给） |
| `joint_waypoints` | 关节多路点（1..8 个用户路点） |
| `joint_console` | 终端/Qt 交互式关节运动 |
| `cart_move` | 相对当前位姿的笛卡尔平移（严格保持姿态） |
| `cart_waypoints` | 笛卡尔多路点（每点 7 值 `x,y,z,qx,qy,qz,qw`） |
| `pos_move` | 基座系绝对位置，可选 `orientation` 约束工具 z 轴 |
| `box_move` | 读取视觉目标面，工具 z 对齐面 z |
| `admittance_move` | 导纳控制下的期望轨迹 |
| `tool` | 末端执行器开关量（**当前无订阅者，实机气泵恒 0**） |
| `teach` | 示教（实机拒绝） |
| `measure` | 参数辨识测量（实机拒绝） |

## 运行序列

```bash
# 一条龙
ros2 launch launch_pack arm_task_sim.launch.py task_sequence:=pos_move_demo

# 只起任务节点（已有仿真/实机）
ros2 run tasks task_runner --ros-args -p task_sequence:="pick_demo" \
    -p exit_when_idle:=true -p use_sim_time:=true
```

`task_runner` 退出码反映序列成败；`exit_when_idle:=true` 时序列结束后退出。
`tasks.yaml` 里有几条**预期失败**的反例：`reset_then_cart`、`unreachable_near`、
`unreachable_far`，退出码 1 是正确行为，且失败方式都是“下发前被拒绝、完全不运动”。

## 多路点

- 用户给 1..8 个路点，任务层自动在最前面补当前位姿作起点；
- `duration` 可选，不给则由控制器按速度/加速度/jerk 限位取总时长；
- 一条轨迹中途不停顿，需要停顿就拆成两个步骤；
- 验收工具 `waypoint_check` 必须在轨迹执行前启动。

## real-compat 验收序列

**触发时机**：实机首次上电前必做（见 [实机首次运行](04-实机首次运行与标定.md) Phase 3.5）。
在 5 自由度仿真里复现 joint6 锁死，把「5 维下哪些任务不可行」提前暴露出来。

相关文件：

| 文件 | 作用 |
| --- | --- |
| `arm_model/model/scene_real_compat.xml` | 无视觉 real-compat 场景 |
| `arm_model/model/scene_vision_raised_real_compat.xml` | 抬高箱体/相机的 real-compat 视觉场景 |
| `arm_model/model/robotic_arm_real_compat.xml` | 与主模型只差 `motor6 gear=0`；场景里用 equality 把 joint6 约束到 0 |
| `launch_pack/config/ros2_controller_real_compat.yaml` | `real_mode=true`、`task_dim=5`、`allow_constrained_traj=true` |

| 序列 | 性质 | 通过判据 |
| --- | --- | --- |
| `real_compat_joint` | 关节空间 | 退出码 0；joint6 全程接近 0；无关节限位告警 |
| `real_compat_pos` | 纯位置 | 退出码 0；位置残差 ≤ `1e-3 m`；姿态漂移告警可以出现 |
| `real_compat_box` | 位置 + 工具轴 + 视觉 | 退出码 0；位置残差 ≤ `5 mm`；工具轴误差 ≤ `1°`；**不允许回退 position-only** |
| `real_compat_joint6_lock` | **预期失败** | 退出码 1；joint6 目标 0.5 rad 但 `/joint_states` 里 joint6 仍接近 0 |

```bash
# 关节与纯位置
ros2 launch launch_pack arm_task_sim.launch.py \
  task_sequence:=real_compat_joint headless:=true show_rviz:=false \
  mujoco_model:=$(ros2 pkg prefix arm_model)/share/arm_model/model/scene_real_compat.xml \
  controller_overlay:=$(ros2 pkg prefix launch_pack)/share/launch_pack/config/ros2_controller_real_compat.yaml

# 视觉与工具轴
ros2 launch launch_pack arm_task_vision_sim.launch.py \
  task_sequence:=real_compat_box headless:=true show_rviz:=false vision_display:=false \
  mujoco_model:=$(ros2 pkg prefix arm_model)/share/arm_model/model/scene_vision_raised_real_compat.xml \
  controller_overlay:=$(ros2 pkg prefix launch_pack)/share/launch_pack/config/ros2_controller_real_compat.yaml
```

> `real_compat_box` 用的是 `box_pregrasp_5dof_high`，不是 6 自由度的 `box_pregrasp`：joint6 锁死后
> 夹爪朝向改变，会挡住相机看到的目标面；从箱体上方接近可以避开遮挡。换箱体/相机位置后这个
> 粗定位点必须重算。
>
> 任一条不通过（或 `real_compat_box` 回退到 position-only），**不要**在实机上启用
> `allow_constrained_traj`；先判断是「5 维不可达」「目标面选错」还是「检测被遮挡」。
