# ADR-20261013-1202：参数辨识采用 FIGAROH + CMA-ES

- 状态：已采纳
- 日期：2026-10-13 12:02
- 相关：[O8](../../bugs/2026-10-13/1202-辨识加速度由速度二次求导.md)、[O10](../../bugs/2026-10-13/1035-激励轨迹不可复现且欠收敛.md)、[O11](../../bugs/2026-10-13/2226-激励轨迹撞地面污染辨识.md)、[O12](../../bugs/2026-10-17/1634-激励轨迹缺碰撞约束.md)、[C7](../2026-11-13/1928-设计约束C1-C10.md)

## 背景

机械臂的保持与重力前馈需要可信的质量/惯量参数，但 CAD 值与实物有偏差。
需要一条“激励轨迹 → 测量 → 离线辨识 → URDF 回写”的完整链路，并且结果必须物理可行。

## 决策

- **辨识**：使用 vendored FIGAROH 做基参数最小二乘，再用 SDP/LMI 做物理一致性投影；
  默认 `physical_projection: true`，因为真值模型本身贴在可行集边界上（link5 伪惯量最小
  特征值仅 6.4e-6）。
- **激励轨迹**：CMA-ES 优化傅里叶级数系数；种子可固定（`measure_trajectory_seed`），
  评估次数提高到 1500，sigma 降到 0.25，并加可行缩放兜底；约束包括关节限位、地面净空、
  自碰撞/连杆-地面碰撞、指令力矩可行性。
- **测量**：控制器 `measure` 状态直接记录 MuJoCo 的 `qacc` 与仿真时间，不再对速度二次求导。
- **禁止**：不要把辨识输出当作下一轮辨识的先验（C7）。

## 备选方案

- **直接使用 CAD 参数**：零成本，但与实物偏差大，重力前馈静差明显。
- **纯最小二乘、不做物理投影**：可能得到负惯量，控制器不可用。
- **随机傅里叶激励**：实现简单，但不可复现、容易越限/撞地/自碰撞，已实测报废数据。
- **把上一轮辨识结果当先验反复迭代**：误差会沿零空间逐轮放大（30 轮 0.29% → 272.7%），明确禁止。

## 后果

- 好激励下参数误差约 0.0011%，默认配置约 0.39%，物理校验通过；
- 激励轨迹生成约 50 s，`arm_measure_sim.launch.py` 的 `step_timeout` 默认 240 s；
- 验证不能看报告里的 `rmse`（量的是投影前基参数），要用 `verify_torque.py` 拿最终 URDF 正演；
- 实机不上报加速度，`measure` 在实机模式下被拒绝。
