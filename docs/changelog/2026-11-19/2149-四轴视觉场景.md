# 变更：4 轴视觉场景与 box_move 演示

- 日期：2026-11-19 21:49
- 类型：功能 / 兼容性
- 相关：[O26 追踪器锁到 IK 无解面](../../bugs/2026-11-19/2149-四轴视觉锁定不可达面.md)、
  [03 视觉链路](../../execute/03-视觉链路.md)、[02 仿真运行](../../execute/02-仿真运行.md)

## 变化

1. 新增 `src/arm_model/model_4dof/scene_vision.xml`：固定深度相机
   `vision_camera` 在 (0.05, −0.55, 0.175) 斜看箱心，红色目标箱 0.35 m 立方、
   中心 (0.35, 0.183, 0.175)、绕 z 45°，落地。`scene.xml` 不动（辨识/测量共用）。
2. `arm_task_vision_sim.launch.py` 与 `view_sim.launch.py` 的默认场景改指
   `model_4dof/scene_vision.xml`；`arm_controller_test_sim.launch.py` 的 `mujoco_model`
   默认值改指 `model_4dof/scene.xml`（此前仍指 6 轴 `model/`）。
3. `check_sim_vision` 真值参数化：新增 `box_normals`（每 3 个数一个外法线）与
   `expected_mode`（single / dual / triple / auto），删除 `box_yaw_deg`；
   默认真值改为 4 轴场景，`tolerance_size_m` 15 mm → 25 mm（见 O26 附）。
4. `tasks.yaml`：`box_move.tool_offset` 0.039 → 0.07；`points.above_box` 改为
   `[0.75, 2.05, -1.44, -1.16]`；删除 `box_move_low` 序列。
5. 所有工具/文档里的模型默认路径统一到 `model_4dof/`（`identify.yaml`、`verify_torque.py`、
   `arm_measure_sim`、`arm_mujoco_sim`、README、CLAUDE.md、`docs/execute/02`、`06`）。

## 兼容性

- 4 轴分支不再支持 6 轴的 `model/scene_vision*.xml`（几何完全不同，混用会让 MuJoCo
  里的连杆与 URDF/TF 不是同一台臂）。
- `box_move_low` 序列不存在了：`arm_task_vision_sim.launch.py task_sequence:=box_move_low`
  会直接报错。4 轴下没有「抬高 / 低处」的能力差异，只剩一条 `box_move_demo`。
- `check_sim_vision --ros-args -p box_yaw_deg:=...` 失效，改用 `box_normals`；
  双面/三面场景传多组法线即可，`expected_mode=auto` 按法线个数判定。
- `box_move` 在 4 轴下仍是 position-only，`tool_offset` 只决定末端驻点与面的距离。

## 验证

- `ros2 launch launch_pack arm_task_vision_sim.launch.py`（headless、不录包）：
  `box_move finished, position error 0.0016 m`，`box_move_demo` 完成、launch 退出码 0；
- `ros2 run view check_sim_vision`：PASS（面心 1.14 mm、法线 0.03°、箱心 4.24 mm、
  边长 17.9 mm / 门限 25 mm、dual 30 帧）；
- 离线 mujoco：箱体投影占画面 38%×54% 且完全在框内；`reset → above_box → 目标`
  关节空间 41+31 点与 Cartesian 12 点全程 0 碰撞。
