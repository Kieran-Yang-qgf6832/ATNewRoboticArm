# 变更：天块/地块识别仿真基准

- 日期：2026-11-21 11:42
- 类型：功能 / 工具
- 相关：[aburobocon-block-pick 仿真基准](../../../src/aburobocon-block-pick/README.md)

## 变化

1. 新增 `src/aburobocon-block-pick/tools/sim_scene.py`：包内独立 MuJoCo 场景，
   黄色赛场地面、45° 俯视相机（640×480、fx≈610）、20cm 双色天块、35cm 纯色地块；
   渲染 RGB-D 并按 RealSense 经验模型叠加深度噪声、边缘飞点与彩色噪声。
2. 新增 `tools/bench_sim.py`：并排/仅天块/仅地块/叠放各 10 个种子、遮挡与画面截断
   各 5 个，每帧 clean/noisy 各跑一遍；统计边长、抓取点、yaw、分类/漏检/误检与
   `skyblock.pipeline.run()` 端到端耗时；结果写 `out/bench/`，失败帧存标注图与场景 XML。
3. `requirements.txt` 增加 `mujoco>=3.2`（仅基准需要）；包 README 增加“12. 仿真基准”。
4. 环境安装 `open3d==0.20.0`（不升级 numpy）。
5. 新增 `scripts/run_sim.py`：非 headless 实时检测入口，打开 MuJoCo 3D 查看器与
   2×2 检测 mosaic（相机视图 / 颜色掩膜 / 检测标注 / 逐块误差），默认 `pair seed=0`。
   为支持 `cv2.imshow`，环境把 `opencv-python-headless` 换成带 GUI 的
   `opencv-python==4.10.0.84`；`requirements.txt` 本来就是 `opencv-python`。

## 结果（2026-11-21 本机，相机距工位中心 1.41m）

- noisy 一组：期望 60 个真值块，命中 48，分类正确 48，漏检 12，误检 0。
- 命中帧精度：边长绝对误差均值 6.5mm / P95 10.7mm；抓取点位置 P95 12.9mm；
  yaw P95 0.7°。
- 速度：`run()` 中位数 180ms（约 5.5 FPS）；并排 293ms、叠放 440ms、
  遮挡/截断 102ms。
- 判定 FAIL：12 个漏检全部来自天块。仅天块场景 noisy 只检出 1/10，clean 2/10，
  与噪声无关；失败帧的可见侧面被 RANSAC 拆成不完整小面，`fill/wh` 不达标后
  按保守策略降级为 `unknown`。
- 遮挡组 clean 出现 1 次误检：遮挡物只压住轮廓一角，深度突变落在掩膜边界而非内部，
  `boundary.occluded` 未触发，最终以 17.9cm 判为天块。
- 两折去偏：反算 `edge_bias_px=1.60`（默认 1.5），验证集边长均值 6.1mm。

## 兼容性

- 只新增包内工具，不修改 `skyblock` 算法代码，不引用 `arm_model`、不启动 ROS 2；
  机械臂仿真链路与控制器配置不受影响。
- 基准依赖 MuJoCo 无头渲染（默认 `MUJOCO_GL=egl`）；无 EGL/GLFW 的机器需先解决渲染后端。

## 验证

- `python3 tools/bench_sim.py`：50 帧 × clean/noisy 跑通，退出码 1（按约定阈值 FAIL），
  输出 `out/bench/summary.md`、`frames.csv`、`summary.json` 与 `fail/` 标注图。
- `python3 scripts/run_sim.py --case pair --seed 0`：3D 查看器 + 2D mosaic 正常打开，
  循环约 3 FPS；首帧检出 sky 200.8mm（err +0.8mm）、earth 342.7mm（err −7.3mm），
  两块均分类正确。
- `python3 docs/tools/check_docs.py`：OK。
