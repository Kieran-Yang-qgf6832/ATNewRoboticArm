# 变更：任务层改为配置驱动

- 日期：2026-10-09 20:10
- 类型：重构
- 相关：[ADR 任务层配置驱动](../../adr/2026-10-07/0907-任务层采用配置驱动执行器.md)

## 背景

旧任务层由 7 个 C++ 任务类组成，新增/调整任务都要改代码并重新编译；调试动作序列很慢。

## 变更

- 任务定义迁移到 `src/tasks/config/tasks.yaml`；
- 新增 `task_executor` 按步骤表执行，步骤类型封闭集合集中在 `step_types.cpp`；
- 控制器侧 FSM 与任务层彻底分离，任务层运行在普通 ROS 线程。

## 影响与迁移

- 新增任务只改 YAML；新增步骤类型才改 C++；
- 旧 C++ 任务类删除；
- 失败语义改为“下发前拒绝、控制器回 `idel`”，不再有半途失败。

## 验证

`reset_only` / `reset_then_joint` / `ready_then_cart` / `pick_demo` 等序列端到端通过；
反例 `reset_then_cart` / `unreachable_*` 按预期被拒绝。
