# 变更：多路点 C3 轨迹规划

- 日期：2026-11-12 14:55
- 类型：功能
- 相关：[多路点 C3 ADR](../../adr/2026-11-12/1455-多路点采用C3七次Bezier规划.md)

## 背景

任务层需要 1..8 个用户路点的连续轨迹；旧方案逐段独立缩放时长，起点微小变化
会让曲线过冲撞限位。

## 变更

- 新增 `joint_waypoints` / `cart_waypoints` 步骤；
- 新增 `WaypointTrajCmd` 消息与 `/arm_joint_waypoints` / `/arm_cart_waypoints` 话题；
- 分段七次 Hermite/Bezier，C³ 连续；各段时间按弦长成比例，再乘全局时间尺度；
- 新增 `multi_traj_max_vel` / `multi_traj_max_acc` / `multi_traj_max_jerk` 参数；
- 新增离线自检 `waypoint_planner_test` 与验收工具 `waypoint_check`。

## 影响与迁移

- 一条轨迹中途不停顿；需要停顿就拆成两个步骤；
- 笛卡尔路点先逐点 IK，再转关节空间规划；
- `allow_constrained_traj=false` 时 `arm_cart_waypoints` 在下发前拒绝。

## 验证

16 条多路点序列端到端通过：关节误差 ≤ 0.000152 rad，笛卡尔终点残差
0.0002–0.0010 m，acc 峰值 ≤ 1.02、jerk 峰值 ≤ 9.24。
