# F10 退出码掩盖任务失败【中】（原 bugs.md A5）

> 严重度：中 ｜ 状态：已修 ｜ 提交：`59bc567` ｜ 日期：2026-10-08 16:21

**现象**

任务链失败时进程仍以 0 退出，上层脚本会当成成功。

**修复**

`TaskRunner::run()` 记录最后一条序列的结果，退出时据此返回退出码。实测：失败序列 → 1，成功序列 → 0。
