# O27 4 轴分支残留 6 轴标定工具与死参数：joint_calibrate 发 6 维轨迹导致点动故障

> 严重度：中 ｜ 状态：已修 ｜ 日期：2026-11-20 1826

## 现象

按 `docs/execute/04` 第 5.3 节做 4 轴实机 `dir` 标定：

```bash
./build/arm_controller/joint_calibrate --ros-args -p joint:=1 -p step:=0.05
```

工具能切进 `joint_traj`，但机械臂不动，控制器报关节轨迹采样故障
（`fault_stage = Joint trajectory sampling`），随后回到保持。工具本身也没有报错。

同一工具还有三个不一致：

- `-p joint:=5` 能通过参数校验，但 4 轴模型没有 joint5；
- `docs/execute/04` 的 `-p print_zero:=true` 报「参数未声明」，文档承诺的功能在分支上不存在；
- `view calib.launch.py` 默认 `robot_effector_frame=link6`、标定名 `arm5dof_realsense`；
- `controller.cpp` 仍声明 `task_dim`（默认 6），全仓无人读取。

## 根因

`joint_calibrate.cpp` 是 6 轴时期版本，三处写死 6：

```text
kJointNames = joint1..joint6            // 关节名写死 6 个
joint 参数校验 1..5                      // 4 轴下 joint5 也能通过
轨迹点 pos 长度 = kJointNames.size() = 6 // 与 6 轴控制器匹配
```

4 轴控制器 `joint_count_ = 4`，`arm_fsm.cpp` 在 `JointTrajState::run()` 的
MOVING 分支用 `point.pos.size() != joint_count_` 判定采样结果，6 维采样第一帧就
判失败并进 STOP —— 所以工具看起来「切换成功」，臂却一步没走。

`print_zero` 与 `calibration_file` 参数同样缺失：`docs/changelog/2026-11-13`
记录过该功能，但 4dof 分支上的工具文件是更早的版本。

## 修复

1. `tools/joint_calibrate.cpp` 去掉关节名硬编码：从 `/joint_states` 里筛出
   `jointN` 并按编号排序（`-p joints:=[...]` 可显式覆盖），轨迹按实际关节数发送；
   `joint` 校验改为 `1..N`。
2. 恢复 `print_zero` 模式与 `calibration_file` 参数：读取标定 YAML 的 `dir/zero`，
   按 `zero_new = zero_old + dir × q_urdf` 生成可粘贴片段，只打印、不写文件、不运动。
   未显式指定 `joint` 时打印全部关节，指定时只打印该关节。
3. `CMakeLists.txt` 为 `joint_calibrate` 补 `ament_index_cpp`、`yaml_cpp_vendor` 与
   `yaml-cpp::yaml-cpp`（标定表解析与默认路径定位）。
4. `view/launch/calib.launch.py`：`robot_effector_frame` 默认 `link6` → `link4`，
   标定名 `arm5dof_realsense` → `arm4dof_realsense`，docstring 同步。
5. 删除 `controller.cpp` 的 `task_dim` 声明（真参数是 `task_space_dof`）；
   清理 `controller.cpp`、`tasks/executor` 里 link6 / joint6 的文案。

## 验证

- `colcon build --packages-select arm_controller tasks view --symlink-install`：通过。
- 假 `/joint_states`（4 个关节）跑 `-p print_zero:=true`：
  自动识别 `joint1..joint4`，输出 4 行片段；`joint2` 的 `q_urdf=0.03`、`dir=1` →
  `zero=0.030000000`。
- 同一输入加 `-p joint:=1 -p calibration_file:=<6 轴标定表>`：
  只打印 `joint1`，`dir=-1`、`q_urdf=0.1` → `zero=-0.100000000`（符号方向正确）。
- 真机点动（4 轴 `joint_traj` 实际动作）未在本机验证，需接硬件复测。
