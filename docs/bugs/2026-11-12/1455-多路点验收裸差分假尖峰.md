# O15 多路点轨迹验收：位置裸差分造出 acc/jerk 假尖峰【中】（验证工具问题，已修）

> 严重度：中 ｜ 状态：已修 ｜ 提交：`052494b` ｜ 日期：2026-11-12 14:55

> 2026-11-12。新增 `joint_waypoints` / `cart_waypoints`（各 8 条序列）后的验收过程中发现。
> 不是轨迹缺陷，是**验证方法**缺陷。

**现象**

16 条多路点序列在仿真里全部执行成功，任务层报的终点残差 **0.0000 rad**；但拿
`/joint_states` 的位置序列做裸二阶/三阶差分复核平滑度时，acc ≈ **3.1 rad/s²**、
jerk ≈ **1548 rad/s³**，远超规划限位 2 / 10，验证脚本一度判为失败。

**根因**

1. 500 Hz 伺服跟踪纹波（每拍都在目标附近小幅修正）被三阶差分放大约 `1/dt³`
   （dt = 2 ms 时约 1.25e8 量级），纹波直接淹没解析轨迹的导数；
2. `/joint_states` 偶发丢拍（实测 4–6 ms 的空档），固定步长差分把时间空档当成真实采样
   间隔，产生虚假尖峰。

**解决**

`src/tasks/tools/waypoint_check.py` 改为：先按 `header.stamp` **线性重采样**到等间隔，
再用 **Savitzky-Golay**（默认窗口 **0.20 s**、`polyorder 3`）求 deriv=1/2/3。平滑后
`waypoints_joint_8` 的峰值为 0.21 rad/s、**1.02 rad/s²**、**9.14 rad/s³**，与规划器
"按 jerk 限位取最短总时长"的预期一致（判定阈值 2.25 / 11.5，留了余量）。

**教训**

- **验证轨迹平滑度不能对位置裸差分**：位置上的毫米级纹波在二阶/三阶导数上就是数量级
  的噪声，而且采样丢拍会让差分结果不可复现地漂。要么用规划器的解析导数，要么先做
  时间戳重采样 + 低通/拟合求导。
- **解析性质与执行效果要分开证**：C³ 连续性、起止导数为零、限位与时长覆盖由离线
  `build/arm_controller/waypoint_planner_test` 直接验证（1..8 个用户路点全覆盖）；仿真只
  负责验证**执行链路**与**低通后的导数**。不要拿差分噪声去否定离线已经证明的解析性质。
