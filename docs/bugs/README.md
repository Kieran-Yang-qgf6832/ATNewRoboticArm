## 历史范围

原台账覆盖 `src/arm_controller`（控制器/状态机/求解器）、`src/tasks`（任务层）、
`src/arm_model`（模型）、`src/launch_pack`（launch/config）与 `src/view`（视觉）。
起点是任务层从“7 个 C++ 任务类”重构为配置驱动执行器时暴露的一批缺陷；此后又做了
笛卡尔失败、实机联调、参数辨识、视觉链路与 real-compat 仿真等专项排查。
